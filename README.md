# 🗄️ EstudoBDR | Banco de Dados Relacional & SQL

Repositório dedicado aos meus estudos práticos de **Banco de Dados Relacional (BDR)**, focado na linguagem **SQL** e no SGBD **MySQL**, com integração ao ecossistema **Java Backend**.

---

### 🎯 Objetivos de Estudo

- [x] Modelagem de Dados Relacional (DER, tabelas, chaves primárias e estrangeiras)
- [x] Linguagem DDL (*Data Definition Language*): `CREATE`, `ALTER`, `DROP`
- [x] Linguagem DML (*Data Manipulation Language*): `INSERT`, `UPDATE`, `DELETE`
- [x] Consultas e Filtros com DQL (*Data Query Language*): `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`
- [ ] Relacionamentos complexos e Junções (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`)
- [ ] Integração do banco com aplicações **Java** (JDBC / Spring Data JPA)
